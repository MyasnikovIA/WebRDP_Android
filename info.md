Инструкция для вашего TV-бокса:

Подключите бокс к сети и включите ADB (в настройках разработчика).

С компьютера выполните команду: adb connect IP_БОКСА

Затем выполните: adb shell appops set ru.miacomsoft.webrdp PROJECT_MEDIA allow

После этого при перезагрузке бокса приложение сможет запускать трансляцию экрана полностью автоматически (без кнопки «Start now»). В коде выше я добавил проверку этого флага и запуск сервиса «втихую».
